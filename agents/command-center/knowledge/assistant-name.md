# Your assistant's name

assistant answers to it and speaks as it. Change it here once and both change. The dashboard reads
this file from your team repo; it has no separate name box once this file exists.

`/command-center-onboarding` writes it. You can also type over it yourself: one plain name, 1 to 40
characters, on the `Name:` line below, then commit. Until it is set, both use "Command Center".
